# KERJAKU Interior Studio 

PROJECT NAME:



KERJAKU Interior Studio





OBJECTIVE:



Build an AI-powered interior sales operating system for interior workshops, especially kitchen set businesses.



This is NOT a simple AI image generator.



The goal is to help interior workshops convert client inquiries into real projects:



Client Inquiry

↓

Consultation

↓

AI Visual Concept

↓

Design Approval

↓

Proposal Generation

↓

WhatsApp Delivery

↓

CRM Follow Up

↓

Project Deal

↓

Production





CORE PRODUCT POSITIONING:



KERJAKU Interior AI is an AI employee for interior workshops.



It helps workshops:

- understand client needs

- create visual concepts

- prepare professional proposals

- communicate with clients

- manage follow ups

- increase project conversion
